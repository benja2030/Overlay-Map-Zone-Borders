# Overlay Map: Zone Borders

The zone outlines for [Overlay Map](https://github.com/benja2030/Overlay-Map-WoW-Forever)'s **Zone Border** option, as a separate download: they're much bigger than the rest of the addon, and only needed if you use that option. Install it next to Overlay Map; it's loaded only when Zone Border is on.

What's in it: one outline per zone and capital city of Kalimdor and the Eastern Kingdoms (`Zone/<map ID>.tga`), a soft version of each (`s`), and the versions for each Outside Your Zone opacity (`d5` to `d60`, and `d70` to `d90` for the fade between outlines).

Also the shape of 248 caves, mines and underground places (`Cave/<n>.tga`, soft `<n>s.tga`, listed in `Caves.lua`), for Zone Border inside them with OpenMap, which draws them on its map.

# Overlay Map: Zone Borders (español)

Las formas de las zonas para la opción **Borde de la zona** de Overlay Map, como descarga aparte: pesan mucho más que el resto del addon y solo hacen falta si usas esa opción. Instálalo junto a Overlay Map; solo se carga cuando Borde de la zona está activado.

Incluye también la forma de 248 cuevas, minas y lugares subterráneos, para el Borde de la zona dentro de ellas con OpenMap (hechas con las imágenes del minimapa del juego).
