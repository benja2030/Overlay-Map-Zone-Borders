# Overlay Map: Zone Borders

The zone outlines for [Overlay Map](https://github.com/benja2030/Overlay-Map-WoW-Forever)'s **Zone Border** option, as a separate download: they're much bigger than the rest of the addon, and only needed if you use that option. Install it next to Overlay Map; it's loaded only when Zone Border is on.

What's in it: one outline per zone and capital city of Kalimdor and the Eastern Kingdoms (`Zone/<map ID>.tga`), a soft version of each (`s`), and the versions for each Outside Your Zone opacity (`d5` to `d60`, and `d70` to `d90` for the fade between outlines).

## Credits

- Each zone's outline was made from the game's own map pictures (its exploration pieces put together).
- Ironforge and Undercity: from their indoor minimap pictures, placed with the TerrainWorldMap addon's tables (MIT licence, `LICENSE-TerrainWorldMap.txt`).
- Thunder Bluff and Darnassus: from the game's terrain data.
- Stormwind and Orgrimmar: from the Waymark addon (MIT licence, `LICENSE-Waymark.txt`).
